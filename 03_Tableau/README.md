# Tableau dashboards

This portfolio includes three packaged Tableau workbooks with embedded Hyper extracts.

| Project | Primary analyst focus |
|---|---|
| [Superstore 360 Executive Dashboard](Superstore_360_Executive_Dashboard/README.md) | Sales, profit, customers, products, geography, discounting, shipping, and time trends |
| [Bookshop Visual Storytelling Dashboard](Bookshop_Visual_Storytelling_Dashboard/README.md) | Pricing, sales, ratings, seasonal patterns, and visual storytelling |
| [UK Bank Customers Dashboard](UK_Bank_Customers_Dashboard/README.md) | Customer segmentation by age, balance, gender, job classification, and region |

All three are `.twbx` packages rather than loose `.twb` files. The embedded extracts make them portable for viewing. Original external source files are not included, so refreshing the data may require reconnecting source files.
