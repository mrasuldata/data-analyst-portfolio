# Bookshop Visual Storytelling Dashboard

## Objective

Explore publishing and book-performance patterns using a portable Tableau workbook with an included Hyper extract.

## Dashboard themes

- **The Launch Window:** debut timing and publishing seasonality
- **The Margin Manifesto:** pricing, discount, format, and price-realization patterns
- **The Publishing Pulse:** sales, ratings, checkouts, popularity, genre, and publisher comparisons

## Workbook

`workbook/Bookshop_Visual_Storytelling_Dashboard.twbx`

The workbook is packaged, so its included extract travels with the file. Open it in Tableau Desktop or Tableau Public. Refreshing from the original Excel source would require reconnecting that source.

## Analyst considerations

The dashboard supports exploratory comparison rather than causal conclusions. Popularity, ratings, sales, and publishing choices may be related to many factors not represented in the extract.

## Data context

This is a coursework/portfolio dashboard. The exact original external dataset source was not documented in the source repository.
