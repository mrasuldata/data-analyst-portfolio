# UK Bank Customers Dashboard

A packaged Tableau dashboard that explores an educational banking-customer dataset by age, account balance, gender, job classification, and region.

## Portfolio artifact

- **Workbook:** [`workbook/UK_Bank_Customers_Dashboard.twbx`](workbook/UK_Bank_Customers_Dashboard.twbx)
- **Format:** Tableau packaged workbook with an embedded Hyper extract
- **Dashboard:** Executive Dashboard
- **Worksheets:** Distribution by Age, Distribution by Balance, Gender, Job Classification, and Map

## Analyst use cases

- Describe the customer population by demographic and account characteristics.
- Compare regional customer distribution.
- Segment customers using age and balance bands.
- Present multiple customer dimensions in a compact executive dashboard.

## Important scope notes

- This is an educational dataset, not real customer banking data.
- The original CSV is not included. The packaged extract supports viewing, but source refresh requires the original file.
- Package integrity and embedded-extract presence were checked automatically. Visual rendering and filter behavior should be reviewed once in Tableau Desktop or Tableau Public before quoting specific figures.
